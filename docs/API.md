# API Reference

Base URL: `/api/v1`. Interactive docs are auto-generated by FastAPI at `/docs` (Swagger) and `/redoc`.

## Authentication (`/auth`)
| Method | Path | Description |
|---|---|---|
| POST | `/auth/signup` | Create a customer or tailor account |
| POST | `/auth/login` | Email/password login |
| POST | `/auth/refresh` | Exchange a refresh token for a new pair |
| POST | `/auth/logout` | Revoke a refresh token |
| POST | `/auth/google` | Login/signup via Google ID token |
| POST | `/auth/forgot-password` | Request a password reset token |
| POST | `/auth/reset-password` | Reset password using a token |
| GET | `/auth/me` | Get the current authenticated user |

## Users (`/users`)
| Method | Path | Description |
|---|---|---|
| PATCH | `/users/me` | Update profile fields |
| GET/POST/DELETE | `/users/wishlist` | Manage wishlist |

## Tailors (`/tailors`)
| Method | Path | Description |
|---|---|---|
| GET | `/tailors` | Browse approved tailors (filter by city) |
| GET | `/tailors/{id}` | Tailor profile detail |
| GET | `/tailors/{id}/services` | Services offered by a tailor |
| POST | `/tailors/profile` | Create own tailor profile (tailor role) |
| GET/PATCH | `/tailors/profile/me` | View/update own profile |
| POST | `/tailors/services` | Add a service |
| PATCH/DELETE | `/tailors/services/{id}` | Update/remove a service |
| GET | `/tailors/categories` | List service categories |

## Bookings & Measurements
| Method | Path | Description |
|---|---|---|
| POST | `/measurements` | Save a measurement profile |
| GET | `/measurements` | List saved measurements |
| POST | `/bookings` | Create a booking request |
| GET | `/bookings/me` | Customer's bookings |
| GET | `/bookings/tailor` | Tailor's incoming bookings |
| PATCH | `/bookings/{id}/status` | Accept/reject/advance a booking |

## Orders
| Method | Path | Description |
|---|---|---|
| GET | `/orders/me` | Customer's orders |
| GET | `/orders/tailor` | Tailor's orders |
| GET | `/orders/{id}` | Order detail |
| GET | `/orders/{id}/history` | Status change history |
| PATCH | `/orders/{id}/status` | Advance order status |
| POST | `/reviews` | Leave a review on a delivered order |

## Payments (`/payments`)
| Method | Path | Description |
|---|---|---|
| POST | `/payments` | Initiate payment (cash/upi/stripe/razorpay) |
| GET | `/payments/me` | Customer's payment history |
| POST | `/payments/razorpay/verify` | Verify Razorpay signature |
| POST | `/payments/stripe/webhook` | Stripe webhook receiver |

## Chat (`/chat`)
| Method | Path | Description |
|---|---|---|
| POST | `/chat/threads` | Open/reuse a thread with a tailor |
| GET | `/chat/threads` | List threads for current user |
| GET | `/chat/threads/{id}/messages` | Fetch messages |
| POST | `/chat/messages` | Send a message |

## Notifications
| Method | Path | Description |
|---|---|---|
| GET | `/notifications` | List (optionally unread only) |
| PATCH | `/notifications/{id}/read` | Mark as read |

## Admin (`/admin`, requires admin role)
| Method | Path | Description |
|---|---|---|
| GET | `/admin/dashboard` | Platform metrics |
| GET | `/admin/users` | List users |
| PATCH | `/admin/users/{id}/deactivate` | Deactivate a user |
| GET | `/admin/tailors/pending` | Tailors awaiting approval |
| PATCH | `/admin/tailors/{id}/approve` | Approve a tailor |
| GET | `/admin/orders` | All orders |
| POST/GET | `/admin/coupons` | Manage coupons |

## AI (`/ai`)
| Method | Path | Description |
|---|---|---|
| POST | `/ai/measurements/suggest` | Suggest measurements from height/weight/garment |
| POST | `/ai/chat` | General tailoring assistant chat |
| POST | `/ai/recommend` | Fabric/color recommendation |

All protected routes expect `Authorization: Bearer <access_token>`.
